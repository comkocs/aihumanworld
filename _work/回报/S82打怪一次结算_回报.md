# S82 人打怪一次结算整场 · 回报

结论:人打怪(attack 与伏击)一次结算整场,规则键升 balance.v1.13,修为基点 234 → 825。PK、切磋、怪 30 刻再生、掉落、伏击频率不动,打怪行动点仍是 2。

## 一次结算怎么做
- 参与角色对 `archetype: monster` 的战斗,在同一次 resolution 里用现有单回合规则连打:每回合从同一个事迹种子另抽一次(`seed#r0`、`#r1`…),体力逐回合结转。
- 回合上限 8。一方体力到 0 即停:怪到 0 = 胜(怪死,掉落、首杀、reward 都在这一下);人到 0 = 负(照旧扣体力、阵亡与掉修为);同回合双方都到 0 算人胜。
- 打满 8 回合都没到 0 = 平:双方留最后一回合后的体力,都受伤、怪不死。
- 取 8 的理由:一阶一段裸装对 9000 折算的同阶怪,2 万个种子里平均 3.24 回合分胜负,8 回合上限截断 0 次;胜 91.6%、负 8.3%、平 0.1%。战力差大的更快(怪更强时人约 2.8 回合败)。
- 装备磨损只取收场那一回合,不逐回合累加,所以一场只磨一次。
- 切磋、PK、以及任何不是「参与角色打怪」的战斗仍是一次一回合。
- 伏击同步:伏击是怪先手,结算时把参与角色放在攻方、怪放在守方跑整场,再把胜负与体力对调回来;反杀照旧给修为。

## 新数(旧 → 新)
- `combat.monster_kill_xp_bp` 234 → 825。
- 算式:每个地点每阶只有 1 只常驻怪,30 刻再生,一天 `1440 ÷ 30 = 48` 只。要对齐满勤练级,每只需 `满勤 ÷ 48`,一阶 `1188 ÷ 48 = 24.75`,取 `floor(300 × bp / 10000) = 24`,得 bp = 825。
- 一阶每只 7 修为 → 24 修为(潜能 0 → 2);一天 48 × 24 = 1152,比满勤 1188 低 3.0%。二至九阶一天 1776 / 2688 / 3936 / 5904 / 9072 / 13440 / 20160 / 30480,与各阶满勤的差都在 3.1% 以内。
- 一天总账一行:一天最多 48 只 × 每只 24 修为 ≈ 1152(满勤练级 1188)。
- 行动点不调:一天 4320 点打 48 只只用 96 点,调它不改变能打几只,瓶颈是怪的再生。
