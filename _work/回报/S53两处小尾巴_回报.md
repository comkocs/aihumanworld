## 协议登记文字(交 0 号窗登 `docs/协议/动词表_v1.md` §7)
attack:新手保护期内,该角色自己第一次主动对其他参与角色(player / official)发起 attack,保护在该刻结束(对方可于同刻起反击);保护期内攻击 NPC 不结束保护。保护结束刻取「建角刻 + combat.newbie_protect_ticks」与「该角色作为 attacker、目标为参与角色的最早一条 combat_resolved 的刻」两者中较早者。判定依据为已有 events 事实,无新表、无新字段;拒绝信封不变,仍为 NOT_ALLOWED `{ reason: "newbie", until_tick }`。

## 风险
- 保护判定每次攻击多一次 events 聚合查询(只在双方都是参与角色且保护刻 > 0 时);events 表无 (type, tick) 索引,量大时会扫表。
- `until_tick` 在主动攻击后返回的是「第一次主动攻击的刻」而非窗口终点,同刻的反击不被拒。
- 红名段测试改用回拨 `created_tick` 脱离保护,不再推进世界钟;若后续有人依赖那段的世界刻推进,需另行处理。
