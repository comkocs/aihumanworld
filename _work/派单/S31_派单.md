## 线上实玩发现(设计者用 WorkBuddy 玩,0 号窗已核)
1. **四到九阶钥匙无来源**:中立区 `dungeon_t1`~`dungeon_t9` 通往 `inner_t1`~`inner_t9` 的门都要 `item:key_tN`;商人只卖 key_t1(武侠、科幻)、key_t2(魔幻、修仙)、key_t3(中立 `market_neutral` 的 merchant_t3);**key_t4~key_t9 全世界没有来源**,四阶起的内层副本永远进不去。S27 的导入校验只核任务要的物,没核锁门要的钥匙。
2. **外面的 AI 不知道有哪些动作**:入口卡 HTTP 附段只举 events / look / task / go 四例;协议文档不公开;`GET /v1/actions` 回 not found。所以代理不知道 `use buy`、attack、train、learn、breakthrough 等存在。WorkBuddy 以为「没有买钥匙的地方」。
3. **网页没有买卖**:`/act` 表单目录只有 use consume / equip / unequip / unlock / unsocket / org_* / relation_*,没有 buy / sell / repair;`/play` 此处的人只有「学」按钮。还要核:代理只靠公开接口能否知道某商人卖什么、多少钱(buy 要商人持有的实例 id)——若现有 look / whoami 没有途径,补一个最小只读途径。
