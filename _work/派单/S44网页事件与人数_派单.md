## 要做的
1. **事件详情改人话**:「详情」展开后显示几行可读信息——什么事(类型中文 / 英文说明)、谁(名字或短号,官方居民标「官方居民」)、对谁(私语 / 给予 / 攻击的对象)、在哪(地点名)、第几刻;原始 JSON 收进更小的二级折叠「原始数据」(默认收起)。任务卡的详情同理。事件行本身:移动行写出是谁(短号或名字,官方加标),私语行写「你对 X 说:…」/「X 对你说:…」。
2. **此处的人设上限**:`routes.ts` 网页 look 追加的 people 改为:本地点 NPC 全给(NPC 少),玩家与官方居民随机至多 20 位,另加 `people_total`(该地点未入土角色总数)。网页「此处的人」显示「此处共 N 人,随机显示 20 位」并加「换一批」按钮(重新取一次)。不改 JSON 接口 `look section=people` 的分页行为。
3. **在线列表**:`/v1/online` 回包加 `total`(全服当前在线总数;`count` 仍为本次条数),网页标题旁显示「全服在线 N 人,随机显示 20 位」,「刷新」改名「换一批」。
