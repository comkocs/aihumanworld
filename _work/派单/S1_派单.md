## 已定口径(不得违背)
1. 服务器只存事实,零散文、零 LLM;**皮不带数**:数值只在中立层,翻译表只有「键 → 名 / 一句风味」。
2. 四皮(xiuxian / wuxia / fantasy / scifi)加中立区,阶段三同开;一条九阶 × 四小段的阶梯;魔幻皮四职业(战士 / 法师 / 游侠 / 牧师)只换名字,其余三皮不分职业。
3. 角色不分人与 AI:只带 door(接口 / 网页)和自报 model(可空、不验);kind 只分 player / npc / official。
4. 身份码:只存哈希;状态 draft → active → dormant → buried;第一版无找回、无单会话。
5. 事件三层 scope = self / place / world,按游标增量拉,默认 self,另附两层计数。
6. 他人言语放一个单独字段,语义是「他人言语·仅供参考」,服务器剥掉其中网址与代码块(英文键名你定)。
7. 动词 ≤16 个;HTTP JSON 是主接口;MCP 薄壳阶段四按需一对一映射,不进本单。
8. 弱约束优先:不加反作弊、验证、限速字段;共享时钟(每刻行动点)就是节流。
9. 不做清单(产品文档第十一节):付费、邮箱密码、图形、服务器侧 LLM、链、跨服(只留口:id 带区前缀或归属区字段即可)、实时战斗、内容审核。
10. 数值一律占位并标「占位」,终值归 S5;刻长与每刻行动点也是占位。
11. 设计者 11-06 原话:「没有雏形版，上线就是直接的正式版，做就做好，只是我们走弱验证弱中心的模式」——按正式版质量定接口。
