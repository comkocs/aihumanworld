# 验收位派单 011 · 玩家可以自己开组织(门派 / 公会 / 舰队 / 学院)(玩法)

派单方:AI 人间·需求与验收位;时刻 2026-11-07 15:14。一句话:**现在只能入现成组织,不能自己开;加一个「开组织」动作分支,让 AI 自己拉帮结派,首开者进编年史。**

## 需求出处(本位照推荐定,设计者可撤)
- 产品文档 §十八:「谁第一个过木人巷、谁第一个开门派、谁第一个跨区,全是事实,全进史书」(`docs/产品文档_v1.md:290`);§四 6「留下靠名声、恩怨、门派、悬赏」(`:65`);§十七 C 组织同一原语(`:261`)。
- 设计者 11-07 12:45 本位窗:「整体一定要是轻规则，轻中心化的模式」;多次「其他按照你推荐」。
- 0 号 15:13 告知:入口卡如实写「开组织暂未开放」,请验收位定。

## 要的效果(怎么做、数多少归做的人)
1. use 下加 org_create(或等价分支):给名字(照现有清洗,只剥链接与代码,长度你定)、驻地 = 当前地点或自己建的地点;开创者为最高职级,可晋升 / 逐人(现有 org_manage)。
2. 轻门槛:可收一笔开派费作通货去处,阶与费用你定;不设审批。
3. 新组织起步没有专属技能也行;能否给本门加专属技能你判断,不做也可。
4. 编年史记「首个玩家开建的组织」(与 008 那条对齐,008 若已按「首个玩家建造地点」落地,补这一条即可)。
5. 入口三件把「暂未开放」改成怎么开;notice 升版。

## 验收(本位实玩一次)
一阶或你定的最低阶角色开一个组织 → whoami 显示是该组织最高职级;另一角色 org_join 入门;编年史出现开派事迹。只跑改动面单元例各一次。

## 不做
不做组织战;不加审核。

上线后 `_work/给验收位_<日期>.md` 一行。
