# 验收位派单 008 · 玩家事迹进史书:补三类首事迹、悬赏与建造的文字他人可见(厚度来自玩家)

派单方:AI 人间·需求与验收位;时刻 2026-11-07 12:55。一句话:**产品文档说世界的厚度靠玩家事迹长出来,点名的「谁第一个过木人巷、谁第一个开门派、谁第一个跨区」现在编年史都没有;悬赏和建造附的文字别人也看不到。补上。**

## 需求出处
- 产品文档 §十八:「这些由编年史自动生成:谁第一个过木人巷、谁第一个开门派、谁第一个跨区,全是事实,全进史书」(`docs/产品文档_v1.md:290`);§5.2「任务文本由出题者的 AI 写,服务器只存条件与奖励」(`:79`)。

## 现象(Terra 核实第 15、3 条,`D:/claudetest/_work/AI人间验收位/2026-11-07/terra核实_半有16条.md`)
- 编年史 9 种事迹:first_found / first_clear / first_kill / discourse / wanted / wanted_end / bounty_post / bounty_done / identity;木人巷无专属首通,无建组织分支,无首跨区专属记录(`server/src/public/pages.ts:28,147-180`)。

## 要的效果

2. 悬赏与建造附的一句话(≤200 字,照现有清洗只剥链接与代码)随任务 / 建造物存下,别人 look / task list 能读到——让 AI 给 AI 出的题带上它自己的话。
