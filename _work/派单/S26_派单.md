## 要做的(结果导向,写法你定)
1. **游戏页 `GET /play`**(人在浏览器里玩的一页):
   - 进门两条路:「新建角色」(选皮;魔幻要选职业)或「输入已有身份码」。新建成功后醒目显示一次身份码 + 复制按钮 + 一句「只显示这一次,请存好」。码存浏览器 `localStorage`,只在本浏览器;页上「退出」清掉。码永不进网址、不进服务器日志。
   - 进门后一屏看全:当前地点(名字 + 描述)、出口(每个出口一个按钮,点了就 go)、此处的人与物(物有「拿」,能打的有「攻击」)、背包(能用 / 装备的给按钮)、可接任务与在办任务(接取 / 提交 / 放弃按钮)、修行(开始练功 / 停止 / 学 / 突破)、说话框、最近事件流(每次动作后刷新,另外每 30 秒自动拉一次 events)。动词与参数照 `docs/协议/动词表_v1.md` 与 `server/src/verbs/`,参数由页面从 look / whoami / task list 回包里取,人不手填 id。
   - 名字一律用皮翻译表显示(`content/skins/<皮>/<语言>.json`;皮取角色自己的皮,语言按浏览器:中文 → zh-CN,其他 → en),页面文字随语言中英两套;回包错误码翻成一句人话,原 JSON 收在可展开的「详情」里。
   - 页面走同源 JSON 路由(建议 `POST /play/v1/<verb>`,体与 `/v1/actions/<verb>` 相同,码走 `Authorization` 头),分发时 `door: "web"`(产品文档第六节:网页角色显示「网页」)。翻译表由服务端只读发给页面(如 `GET /play/lexicon/<皮>/<语言>.json`)。
   - JS / CSS 用独立静态件(不内联),加 `Content-Security-Policy: default-src 'self'`;别人说的话、角色名一律按文本插入(`textContent`),不拼 HTML。手机竖屏也能点。不用框架、不用打包步骤(照服务端现行:Node 24 直接跑)。
2. **首页给浏览器一个门**:`GET /` 请求头 `Accept` 含 `text/html` 时回 HTML:醒目的「开始游戏」大按钮 → `/play`;下面是四个皮的入口卡(修仙 / 武侠 / 魔幻 / 科幻,点进各区公开页)、编年史、动作表单目录链接、一句「AI 玩家请把入口 md 交给你的 AI」。其他请求(curl、`Accept: */*`、`text/markdown`)**一字不改**照旧回 Markdown(AI 读的投影与 ETag 不变)。
3. **公开页的浏览器版**:`/chronicle`、`/region/<皮>`、`/place/<id>`、`/char/<id>` 同样按 `Accept` 含 `text/html` 回 HTML(同一份内容转成可点的页,统一深色样式,页顶有四皮切换与「开始游戏」);浏览器版不出现 `translation_missing`:没带 `?skin=&locale=` 时,区页用本区的皮,其他页按语言默认(中文 → xiuxian/zh-CN,其他 → fantasy/en)。Markdown 版不动。
4. **`/act` 表单页**套同一套样式,字段说明改中文(英文页给英文),顶上加「想直接玩?去游戏页」链接;表单行为不变。
5. 风格照上面「深色夜读」;强调色随皮(无皮时用修仙青)。字号适中、行距舒展、按钮够大好点。
