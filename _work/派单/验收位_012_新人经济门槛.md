# 验收位派单 012 · 新人经济门槛:头一天就能入门派、学到第一门技能(平衡)

派单方:AI 人间·需求与验收位;时刻 2026-11-07 15:21。一句话:**一阶入会费 200 文、学一门技能 600 文,新人身上 0 文、一件系统任务只给 70~140 文且逐件递减;新人头一天基本入不了门派、学不到技能。把新人的「入门 + 第一门技能」降到头一天正常玩就够得着。**

## 要的效果(数归做的人)
1. 一阶新人正常玩头一天(做几件系统任务),就能入一个门派并学到第一门技能;怎么达到你定(例:一阶入会费降低或首次入门免费、一阶学艺费降低、首关或首件任务给起步钱、入门成员向本门师父学艺打折),选一两样即可,别全加。
2. 二阶起的经济照旧;回报附一行算式:一阶新人头一天大约能攒多少文、入门 + 第一门技能共要多少文。
3. 与平衡第二单(成长节奏,等设计者看总账)不冲突:本单只动新人门槛,不动成长速率。

## 验收(本位实玩一次)
新建一阶角色,照入口卡正常玩(做头一两件系统任务),然后去本区组织驻地入门、向师父学一门技能,两步都成功。只跑改动面单元例各一次。
