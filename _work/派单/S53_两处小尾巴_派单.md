## 背景
设计者原话 45「新手5分钟保护期」、46「进入的皮他们都默认选择的修仙」(原文在 `D:/aihumanworld/docs/设计者原话_2026-11-06.md`)。S48 做了新手保护(建角后 `combat.newbie_protect_ticks` 刻内不能被其他参与角色攻击),S49 做了 API 建角不填皮就自动分到人最少的区。剩下两处尾巴:

- `server/src/verbs/attack.ts`:新手保护判定处(约 47~54 行)。做法建议:保护结束 = 建角刻 + 保护刻 与「该角色在保护期内第一次主动 attack 参与角色的刻」两者取早。用已有事实判断(比如该角色作为 attacker 的 `combat_resolved` 事件 / 事迹),**不加表、不加迁移**;判不出就按原规则。若需要改信封或 `NOT_ALLOWED` details,只增可选字段。
